fix: A forwarded SSH port now opens in its own job object and is waited for until it really listens, so a dropped connection or a stale forward no longer leaves the tunnel half up.
fix: The terminal's output no longer grows without limit: the ConPTY reader channel is bounded, so a program that floods the screen cannot eat the process's memory.
fix: Opening a link on Windows goes through the shell instead of cmd.exe, so a URL holding characters cmd would read as syntax opens as written.
fix: A command whose executable ends in .exe of either case no longer panics while its process name is matched.
fix: Listing the system's TCP sockets no longer reads an under-aligned buffer.
fix: A new window started as a fallback keeps its console handles, so a task that asks for a console gets one that stays open.
fix: The session host's local socket checks its nonce strictly, accepts connections without blocking, and ignores a PID whose process is gone.
fix: pdftoppm is found on PATH even when it is a shim, and the process tree it starts is closed with it.
fix: A Shell or task run from PowerShell or Cmd starts in its own directory and environment, and a cd with spaces in the path is quoted so it survives.
fix: zoxide is installed by running winget with its non-interactive agreement flags, so a first install no longer stops on a prompt.
